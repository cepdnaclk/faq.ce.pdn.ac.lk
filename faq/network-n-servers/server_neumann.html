This is a HPC server of the Department of Computer Engineering, University of Peradeniya.

This server can be used to run VLSI workflows using Synopsys tools .

You can use this server using the LDAP login for ce.pdn.ac.lk undergraduates (which is used for CO top floor lab, Aiken and Tesla) without sudo access.

What is the IP address of this server? 10.40.18.20 (internal, not accessible from outside the university network) What is the hardware configuration of this server?
  • Dell PowerEdge R440 HPC
  • 2 x Intel(R) Xeon(R) Gold 5218 CPU (2*16 cores, 2*32 threads) @ 3.90 GHz
  • 192 GiB RAM
 What is the operating system of this server? AlmaLinux 10.1 (Heliotrope Lion) x86_64 (binary-compatible with Red Hat Enterprise Linux (RHEL)) What can I do if my doubt is not listed here? Ask the CE Network Admin
